# ⚛️ React Fundamentals

A hands-on **React.js learning project** created to build a strong foundation in modern frontend development and understand the core concepts behind React.


## 📚 What We Learned

### 01 — Why You Should Care About React

Understanding why React is widely used, how it simplifies UI development, and the benefits of building applications with reusable components.

### 02 — Setting Up a New React Project

Learning how to create and configure a React project using **Vite**, manage dependencies with npm, and run the application locally.

### 03 — JSX

Learning how to use **JSX** to write HTML-like UI structures directly inside JavaScript and combine markup with JavaScript logic.

### 04 — Custom Components

Learning how to create reusable components, split the UI into smaller parts, and build applications using React's component-based architecture.

## 🪟 Installation — Windows

Make sure **Node.js** and **npm** are installed on your Windows machine.

Check your installation:

```powershell
node -v
npm -v
```

Create a new React project with Vite:

```powershell
npm create vite@latest my-react-app
```

Select:

```text
Framework: React
Variant: JavaScript
```

Then install the project dependencies:

```powershell
cd my-react-app
npm install
```

Start the development server:

```powershell
npm run dev
```

Copy the **Local URL** displayed in the terminal and open it in your browser.

## ⚡ Quick Start

```powershell
npm create vite@latest my-react-app
cd my-react-app
npm install
npm run dev
```
